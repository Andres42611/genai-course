This week showed me how to build and implement VAEs and GANs into dataset problems, and also how to think critically about the task at hand to know when to use each. I was able to play with certain parameters, such as learning rates, latent representations, and different GAN loss functions, to see what mode collapse looks like and when VAEs or GANs may be more useful. I was honestly surprised to see how well some of these generation tasks, like FashionMNIST, worked with models as simple as the ones we built in this first week. With only 30 epochs and just a bit of setup, I was getting fairly well-generated images to use and work with.
